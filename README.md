# Titanic Survival Data Analysis

This project explores the famous Titanic dataset using **Python** (Pandas, Matplotlib, Seaborn) to uncover insights about passenger survival during the disaster.

## Objective
To perform visual and statistical analysis of the Titanic dataset and identify key factors that influenced survival, such as gender, class, age, and fare.

## Files Included
- `train.csv` – Training dataset containing passenger details.
- `task5DA.ipynb` – Jupyter Notebook with full data exploration and visualization.
- `Titanic Survival Data Analysis Report.pdf` – Final report summarizing findings, visuals, and insights.

## Key Insights
- **Gender**: Females had a much higher survival rate than males.
- **Class**: First-class passengers were more likely to survive.
- **Fare**: Higher fares (indicating higher socio-economic status) slightly increased survival odds.
- **Age**: Younger passengers, especially children, had better chances of survival.

## Tools Used
- Python
  - `pandas`
  - `matplotlib`
  - `seaborn`

## How to Run
1. Clone the repo
2. Open `task5DA.ipynb` in Jupyter Notebook or VSCode
3. Run cells in order to see data analysis and visualizations
